# Contributing to VOLTRA MSME

Contributions should keep this repository focused on the ESP32 based smart home energy system. The grid risk advisor has a separate repository.

## Local workflow

1. Create a branch from `main`.
2. Install frontend and backend dependencies using the steps in [README.md](README.md).
3. Keep readings clearly identified as live, simulated, or estimated.
4. Describe hardware assumptions and calibration requirements for device-facing changes.
5. Open a pull request with a concise summary and screenshots for visible UI changes.
